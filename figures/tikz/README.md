# Book diagrams

These 37 standalone TikZ sources are the original diagrams from *Bayesian Methods for Autonomous Robotics and Intelligent Infrastructure Systems* by Khalid M. Mosalam, with a consistent visual design by Ziad Mosalam. Original diagram authorship is retained. The restyling preserves the mathematical content and diagram relationships.

The shared palette, typography and line styles are in `book-figure-style.tex`. Each source produces the adjacent PDF. Numerical plots generated by the companion notebooks remain in the parent `figures` directory.

## Compile one diagram

With a TeX installation containing `standalone` and TikZ/PGF, run from this directory:

```sh
pdflatex -interaction=nonstopmode -halt-on-error slam-factor-graph.tex
```

Replace the filename to compile another diagram. No Python code, notebook execution or external data files are required. The standalone PDF has a small border for review; its diagram is the same as the corresponding book source.

`figure-sources.json` maps each file to its book source and original figure label. Files with `schematic` in their name illustrate a concept; their drawn curves are not experimental data.
